# Governanca Institucional Meridian — Politica de Aprendizado (/learn)

## 1. Proibicao de Auto-Cristalizacao Autonoma
- Nenhum agente ou assistente deve executar o comando `/learn` automaticamente para transformar toda correcao pontual em regra ou skill permanente.
- Nenhum agente tem autoridade para institucionalizar sozinho uma conclusao potencialmente enviesada ou errada.

## 2. Fluxo Institucional de Aprendizado
```text
Sucesso / Correcao comprovada em teste
        │
        ▼
Candidato a Aprendizado (identificado)
        │
        ▼
Proposta Formal Documentada
        │
        ▼
Revisao Tecnica do NEXUS
        │
        ▼
Criacao/Atualizacao de Rule ou Skill persistente
```
